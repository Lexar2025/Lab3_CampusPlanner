# Campus Planner

Учебный мобильный планировщик задач на базе Campus API. Приложение construit на ветке **Campus Planner** и показывает цельную интеграцию инструментов предыдущих лабораторных работ: навигацию Expo Router, серверные данные через TanStack Query, авторизацию с SecureStore, анимации Reanimated и жесты Gesture Handler.

## Ветка приложения

Campus Planner — планировщик учебных задач с дедлайнами, приоритетами и статусами.

## Основные возможности

- Вход и выход из учётной записи; сессия восстанавливается при запуске.
- Список задач текущего пользователя с загрузкой, пустым состоянием и обработкой ошибок.
- Создание, просмотр, редактирование и удаление задачи через Campus API.
- Поиск по названию и предмету.
- Серверная фильтрация по статусу: «Все», «Активные», «Выполненные».
- Календарный список: задачи группируются по срокам (см. раздел «Собственная функция»).
- Смена статуса свайпом и нажатием на чекбокс; оптимистичный отклик.
- Удаление с подтверждением и пятисекундной отменой.
- Светлая и тёмная тема.
- Обработка отсутствующей записи (404), ошибок API и неавторизованной сессии (401).

## Собственная функция: календарный список

Задачи в основном списке группируются по секциям согласно дате дедлайна:

| Секция | Условие |
| :-- | :-- |
| Просрочено | дедлайн прошёл, задача активна |
| Сегодня | дедлайн на сегодня |
| Завтра | дедлайн на завтра |
| На этой неделе | дедлайн через 2–7 дней |
| Позже | дедлайн через больше 7 дней |
| Без срока | дедлайн не задан или некорректен |
| Выполненные | выполненные задачи, только при фильтре «Все» |

Пустые секции не показываются. В заголовке каждой секции указано количество задач. Секция «Просрочено» выделена цветом. При фильтре «Выполненные» показывается одна секция без дат; при «Активные» — только активные задачи.

Функция реализована через `src/utils/taskSections.ts` (`groupTasksByDueDate`, `buildTaskRows`) и отображается в текущем `Animated.FlatList` со всеми существующими анимациями и свайпами.

```

src/utils/         — хелперы дат, статистика, фильтрация, секции задач
```

## Запуск

1. Установите Node.js 20+.
2. Установите зависимости:

```bash
npm install
```

3. Настройте учебный API. Создайте файл `.env` по примеру `.env.example`:

```
EXPO_PUBLIC_API_URL=https://campus-api.mkseva.workers.dev
```

4. Запустите приложение:

```bash
npx expo start
```

Откройте в Expo Go на телефоне или в эмуляторе Android.

## Учебный API

- Базовый адрес задаётся переменной `EXPO_PUBLIC_API_URL` (по умолчанию `https://campus-api.mkseva.workers.dev`).
- Реальные логины, пароли и токены не хранятся в репозитории. Тестовые учётные данные выдаёт преподаватель.

## Демонстрация

Последовательный показ на 3 минуты:

1. Вход тестовым пользователем.
2. Список задач: загрузка, поиск, переключение фильтров статуса.
3. Создание задачи: форма, сохранение черновика, возврат на список, подсветка новой карточки.
4. Детали задачи: просмотр, смена статуса, редактирование.
5. Свайп-жесты: выполнение swipe вправо, удаление swipe влево, отмена удаления.
6. Светлая и тёмная тема.
7. Выход из учётной записи.

## Сборка Android (EAS)

Реальная сборка в этой среде не выполнялась: нет доступа к EAS. План сборки:

```bash
npx eas-cli@latest init
npx eas-cli@latest build -p android --profile preview
```

Профиль `preview` в `eas.json` собирает внутренний APK. Имя пакета Android: `com.campusplanner.app` (задано в `app.json`). Идентификатор проекта EAS и владелец настраиваются интерактивно при первом запуске `eas init`.
